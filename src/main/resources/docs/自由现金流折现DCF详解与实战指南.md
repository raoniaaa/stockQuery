## 一、自由现金流核心概念

### 1.1 为什么用现金流而非利润？

**会计利润 vs 自由现金流**

| 维度 | 会计利润（净利润） | 自由现金流（FCF） |
|------|-------------------|-------------------|
| **计算基础** | 权责发生制 | 收付实现制 |
| **包含项目** | 应收账款、折旧、摊销 | 实际现金收支 |
| **可操纵性** | 较高（会计估计、政策选择） | 较低（现金是硬指标） |
| **再投资需求** | 不体现 | 明确扣除资本支出 |
| **价值相关性** | 间接 | **直接决定企业价值** |

**核心原则**：
> 企业价值 = 未来能分配给所有资本提供者的现金流的现值

### 1.2 自由现金流的本质

```
自由现金流 = 经营活动产生的现金 - 维持和增长业务必需的再投资

即：企业在不影响持续经营前提下，可自由分配给资本提供者的现金
```

### 1.3 两种自由现金流

| 类型 | 全称 | 归属 | 折现率 | 计算结果 |
|------|------|------|--------|----------|
| **FCFF** | 企业自由现金流 (Free Cash Flow to Firm) | 所有资本提供者（股东+债权人） | WACC | 企业价值（EV） |
| **FCFE** | 股权自由现金流 (Free Cash Flow to Equity) | 仅股东 | 股权成本（Re） | 股权价值 |

**关系**：
```
FCFF = FCFE + 利息费用×(1-税率) - 净借债

或：
FCFE = FCFF - 利息费用×(1-税率) + 净借债
```

## 二、FCFF与FCFE详解

### 2.1 FCFF（企业自由现金流）

**定义**：企业在满足再投资需求后，可向所有资本提供者（股东和债权人）分配的现金。

**计算公式（从EBIT出发）**：
```
FCFF = EBIT × (1 - 税率) + 折旧与摊销 - 资本支出 - 营运资本增加

或：
FCFF = 净利润 + 利息费用×(1-税率) + 折旧与摊销 - 资本支出 - 营运资本增加

或：
FCFF = 经营活动现金流净额 + 利息费用×(1-税率) - 资本支出
```

**各科目详解**：

| 科目 | 说明 | 数据来源 |
|------|------|----------|
| EBIT | 息税前利润，扣除营业成本、销售/管理/研发费用 | 利润表 |
| 税率 | **有效税率**（非名义税率），历史均值或预期 | 利润表/附注 |
| 折旧与摊销 | 固定资产折旧 + 无形资产摊销 + 长期待摊费用 | 现金流量表附注 |
| 资本支出 | **维持性** + **扩张性**资本支出 | 现金流量表/管理层指引 |
| 营运资本增加 | Δ(应收账款+存货-应付账款) + Δ其他流动资产/负债 | 资产负债表变动 |

### 2.2 FCFE（股权自由现金流）

**定义**：企业在满足再投资需求和债务义务后，可分配给股东的现金。

**计算公式**：
```
FCFE = 净利润 + 折旧与摊销 - 资本支出 - 营运资本增加 + 净借债

或：
FCFE = FCFF - 利息费用×(1-税率) + 净借债

或：
FCFE = 经营活动现金流净额 - 资本支出 + 净借债（发行债务-偿还本金）
```

**净借债**：
```
净借债 = 新发行债务 - 偿还债务本金
       = 期末有息负债 - 期初有息负债
```

### 2.3 FCFF vs FCFE 对比

| 维度 | FCFF | FCFE |
|------|------|------|
| **归属对象** | 股东 + 债权人 | 仅股东 |
| **计算起点** | EBIT 或 经营现金流 | 净利润 或 经营现金流 |
| **债务处理** | 不考虑（税前） | 考虑（税后利息、净借债） |
| **折现率** | WACC（加权平均资本成本） | Re（股权成本，CAPM） |
| **估值结果** | 企业价值（EV） | 股权价值 |
| **适用场景** | 资本结构稳定或未知 | 资本结构变化大或已知 |
| **复杂程度** | 相对简单 | 需预测债务变动 |

### 2.4 选择建议

```
资本结构是否稳定？
    ├── 是 → 使用FCFF（更常用，更简单）
    └── 否 → 使用FCFE（需预测杠杆变化）

是否有明确债务偿还/发行计划？
    ├── 是 → FCFE更准确
    └── 否 → FCFF更稳健
```

## 三、从三张报表推导自由现金流

### 3.1 推导路径图

```
利润表                    资产负债表                现金流量表
营业收入                   应收账款                 经营活动现金流
- 营业成本                 + 存货                   - 资本支出
= 毛利                     - 应付账款               = 自由现金流
- 销售/管理/研发费用       = 营运资本
= EBIT
- 利息费用
= 税前利润
- 所得税
= 净利润
```

### 3.2 从净利润推导FCFF（最常用路径）

```
净利润
+ 利息费用 × (1 - 税率)          // 加回税后利息（债权人部分）
+ 折旧与摊销                      // 非现金支出，加回
+ 资产减值损失                    // 非现金支出
+ 递延所得税增加                  // 非现金支出
- 资本支出（CapEx）               // 维持+扩张性投资
- 营运资本增加（ΔWC）             // 经营资金占用
= FCFF（企业自由现金流）
```

### 3.3 从经营现金流推导FCFF

```
经营活动现金流净额
+ 利息费用 × (1 - 税率)          // 经营现金流已扣利息，需加回税后部分
- 资本支出（CapEx）
= FCFF
```

### 3.4 营运资本（WC）详解

**定义**：
```
营运资本 = 经营性流动资产 - 经营性流动负债

经营性流动资产 = 应收账款 + 存货 + 预付账款 + 其他流动资产（不含现金及等价物）
经营性流动负债 = 应付账款 + 预收账款 + 应付职工薪酬 + 应交税费 + 其他流动负债（不含短期借款）
```

**营运资本增加的含义**：
- ΔWC > 0：资金被占用（应收增加、存货积压、应付减少）→ 现金流出
- ΔWC < 0：资金释放（应收减少、存货消化、应付增加）→ 现金流入

**简化计算**：
```
营运资本增加 = (期末WC - 期初WC)
             = Δ应收账款 + Δ存货 - Δ应付账款 + Δ其他经营性项目
```

### 3.5 资本支出（CapEx）详解

**分类**：

| 类型 | 说明 | 识别方法 |
|------|------|----------|
| **维持性资本支出** | 维持现有产能、替换老旧设备 | 折旧摊销 ≈ 维持性CapEx（简化） |
| **扩张性资本支出** | 新增产能、新业务投资 | 总CapEx - 维持性CapEx |

**数据来源**：
- 现金流量表"购建固定资产、无形资产和其他长期资产支付的现金"
- 附注中的资本性支出明细
- 管理层指引（指引未来投资计划）

## 四、预测期现金流建模

### 4.1 预测期长度

| 企业类型 | 预测期 | 理由 |
|----------|--------|------|
| 成熟期企业 | 5年 | 增长稳定，很快达到稳态 |
| 成长期企业 | 7-10年 | 高增长持续较长时间 |
| 初创/转型期 | 10年+ | 盈利尚未稳定，需更长预测 |
| 周期性行业 | 覆盖完整周期（5-7年） | 需覆盖高峰和低谷 |

### 4.2 收入预测方法

**方法一：自上而下**
```
收入 = 市场规模 × 市场份额
     = 行业总需求 × 企业市占率

适用：有明确行业数据和竞争格局分析
```

**方法二：自下而上**
```
收入 = 销量 × 单价
     = (产能 × 产能利用率) × 单价

适用：制造业、有明确产能规划的企业
```

**方法三：增长率法**
```
收入_t = 收入_(t-1) × (1 + g_t)

g_t = 前一年增长率 × 衰减因子（逐步收敛至行业均值）
```

### 4.3 利润率预测

**常用假设**：

| 指标 | 预测方法 | 参考基准 |
|------|----------|----------|
| 毛利率 | 历史均值或趋势外推 | 行业均值、成本结构变化 |
| 销售费用率 | 收入占比法 | 规模效应（收入↑，费率↓） |
| 管理费用率 | 收入占比法 | 固定成本摊薄 |
| 研发费用率 | 收入占比法或绝对额 | 技术战略、竞争需求 |
| 有效税率 | 历史有效税率均值 | 税收政策、税收优惠到期 |

### 4.4 资本支出预测

**方法一：收入占比法**
```
资本支出 = 收入 × CapEx/收入比率

CapEx/收入比率参考历史均值，或管理层指引
```

**方法二：产能驱动法**
```
资本支出 = 新增产能 × 单位产能投资额

适用于制造业、有明确扩产计划的企业
```

**方法三：折旧替代法（简化）**
```
维持性CapEx ≈ 折旧与摊销
扩张性CapEx = 根据增长计划单独预测
```

### 4.5 营运资本预测

**方法一：周转天数法（推荐）**
```
应收账款 = 收入 × 应收账款周转天数 / 365
存货 = 营业成本 × 存货周转天数 / 365
应付账款 = 营业成本 × 应付账款周转天数 / 365

营运资本 = 应收账款 + 存货 - 应付账款
```

**方法二：收入占比法**
```
营运资本 = 收入 × 营运资本/收入比率

营运资本/收入比率参考历史均值
```

### 4.6 预测期FCF计算模板

| 项目 | 第1年 | 第2年 | ... | 第n年 |
|------|-------|-------|-----|-------|
| 营业收入 | | | | |
| 营业成本 | | | | |
| **毛利润** | | | | |
| 销售/管理/研发费用 | | | | |
| **EBIT** | | | | |
| 利息费用 | | | | |
| 税前利润 | | | | |
| 所得税 | | | | |
| **净利润** | | | | |
| + 折旧与摊销 | | | | |
| + 利息费用×(1-T) | | | | |
| - 资本支出 | | | | |
| - 营运资本增加 | | | | |
| **FCFF** | | | | |

## 五、折现率（WACC）计算

### 5.1 WACC公式

```
WACC = E/(E+D) × Re + D/(E+D) × Rd × (1 - T)

其中：
- E = 股权市场价值（股价 × 总股本）
- D = 债务市场价值（通常用账面价值近似）
- Re = 股权成本（CAPM模型）
- Rd = 债务成本（债券到期收益率或贷款利率）
- T = 有效税率
```

### 5.2 股权成本（Re）——CAPM模型

```
Re = Rf + β × (Rm - Rf) + 规模溢价 + 公司特定风险溢价

其中：
- Rf = 无风险利率（10年期国债收益率）
- β = 股票系统性风险系数
- Rm - Rf = 市场风险溢价（通常4%-7%，中国市场约5%-6%）
- 规模溢价 = 小市值公司额外风险补偿（通常0%-3%）
- 公司特定风险溢价 = 非系统性风险（通常0%-2%）
```

### 5.3 β系数详解

**定义**：股票收益率对市场收益率的敏感度

**计算方法**：
```
β = Cov(股票收益率, 市场收益率) / Var(市场收益率)

回归分析：股票收益率 = α + β × 市场收益率 + ε
```

**去杠杆与加杠杆**：
```
β_资产 = β_权益 / [1 + (1-T) × D/E]        // 去杠杆（去除财务杠杆影响）
β_权益 = β_资产 × [1 + (1-T) × D/E]        // 加杠杆（根据目标资本结构调整）
```

**应用场景**：
- 可比公司β去杠杆 → 得到行业β_资产 → 根据目标公司资本结构加杠杆

### 5.4 债务成本（Rd）

| 企业类型 | Rd确定方法 | 说明 |
|----------|------------|------|
| 有公开债券 | 债券到期收益率（YTM） | 最准确 |
| 无公开债券 | 银行贷款利率 | 参考近期贷款合同 |
| 无贷款记录 | 同行业同评级债券利率 | 需信用评级参考 |
| 初创企业 | 创始人个人信用利率 + 风险溢价 | 粗略估计 |

### 5.5 资本结构权重

**市场价值权重（推荐）**：
```
E = 当前股价 × 流通股本（或总股本）
D = 短期借款 + 长期借款 + 应付债券（账面价值近似市场价值）

注意：
- 股权用市场价值（股价×股本）
- 债务若无活跃交易，用账面价值近似
- 使用目标资本结构（而非当前结构）更合理
```

**目标资本结构确定**：
- 参考行业均值
- 参考管理层指引
- 参考历史均值（若稳定）

### 5.6 WACC计算示例

| 参数 | 数值 |
|------|------|
| 无风险利率(Rf) | 3.0% |
| 市场风险溢价(Rm-Rf) | 5.5% |
| β系数 | 1.2 |
| 股权成本(Re) | 3.0% + 1.2×5.5% = 9.6% |
| 债务成本(Rd) | 5.0% |
| 有效税率(T) | 25% |
| 股权市值(E) | 100亿 |
| 债务市值(D) | 40亿 |
| 股权权重(E/(E+D)) | 71.4% |
| 债务权重(D/(E+D)) | 28.6% |
| **WACC** | **71.4%×9.6% + 28.6%×5.0%×75% = 7.93%** |

## 六、终值计算

### 6.1 为什么需要终值？

企业理论上永续经营，但详细预测期有限（5-10年）。终值代表预测期后所有未来现金流的现值。

**终值占比**：
- 成熟期企业：终值占EV的60%-80%
- 成长期企业：终值占EV的50%-70%
- 若终值占比 > 80%，说明预测期太短，需延长

### 6.2 永续增长模型（Gordon Growth Model）

**公式**：
```
TV = FCF_n × (1 + g) / (WACC - g)

其中：
- FCF_n = 预测期最后一年自由现金流
- g = 永续增长率（通常2%-4%，不超过GDP增速）
- WACC = 加权平均资本成本
```

**关键约束**：
- g < WACC（否则TV为负或无意义）
- g ≤ 长期GDP增速 + 通胀率（通常2%-4%）
- g ≤ 行业长期增长率

**永续增长率确定**：

| 企业类型 | 永续增长率 | 理由 |
|----------|-----------|------|
| 成熟行业龙头 | 2%-3% | 接近GDP增速 |
| 成长期企业 | 3%-4% | 高于GDP，但逐步收敛 |
| 高科技/平台 | 3%-5% | 网络效应，但需谨慎 |
| 衰退行业 | 0%-2% | 行业萎缩，增长受限 |

### 6.3 退出倍数法（Exit Multiple）

**公式**：
```
TV = EBITDA_n × EV/EBITDA倍数

或：
TV = EBIT_n × EV/EBIT倍数

常见倍数参考：
- 制造业：EV/EBITDA = 6-10x
- 消费品：EV/EBITDA = 8-12x
- 科技/SaaS：EV/Revenue = 5-10x
- 成熟行业：EV/EBIT = 8-12x
```

**两种方法对比**：

| 方法 | 适用场景 | 优点 | 缺点 |
|------|----------|------|------|
| 永续增长 | 稳定增长企业 | 与DCF逻辑一致 | 对g敏感 |
| 退出倍数 | 周期性/并购场景 | 反映市场定价 | 受市场情绪影响 |

### 6.4 终值现值计算

```
终值现值 = TV / (1 + WACC)^n

其中n = 预测期最后一年

注意：终值是在预测期末计算的，需折现到当前
```

## 七、企业价值到股权价值

### 7.1 价值恒等式

```
企业价值(EV) = 股权价值 + 有息负债 - 现金及等价物 + 少数股东权益 + 优先股

股权价值 = EV - 有息负债 + 现金及等价物 - 少数股东权益 - 优先股
```

### 7.2 从EV到每股价值

```
每股价值 = 股权价值 / 稀释后总股本

稀释后总股本 = 基本股本 + 期权稀释 + 可转债稀释

期权稀释（库藏股法）：
    稀释股数 = 期权行权股数 - (期权行权价 × 期权股数 / 当前股价)
```

### 7.3 价值构成示意

```
企业价值(EV)
├── 预测期FCF现值
│   ├── 第1年FCF现值
│   ├── 第2年FCF现值
│   └── ...
```

## 十、常见错误与注意事项

### 10.1 十大常见错误

| 错误 | 后果 | 正确做法 |
|------|------|----------|
| 1. 永续增长率 > WACC | TV为负，模型崩溃 | g必须 < WACC |
| 2. 使用净利润代替FCF | 高估/低估价值 | 必须用自由现金流 |
| 3. 忽略营运资本变动 | 现金流预测失真 | 详细预测应收、存货、应付 |
| 4. 资本支出假设不合理 | 增长假设与再投资脱节 | Sales-to-capital ratio验证 |
| 5. WACC计算错误 | 折现率偏差导致估值失真 | 用CAPM+债务成本，考虑税率 |
| 6. 预测期太短 | 终值占比过高（>80%） | 至少5-10年详细预测 |
| 7. 忽略稀释效应 | 每股价值高估 | 考虑期权、可转债 |
| 8. 使用账面价值而非市场价值 | 资本结构权重错误 | 股权用市值，债务用市场价值 |
| 9. 过度乐观的增长假设 | 估值虚高 | 参考行业增速、市占率上限 |
| 10. 忽视敏感性分析 | 风险认知不足 | 必须做WACC和g的敏感性分析 |

### 10.2 利润质量检验

```
净利润 vs 经营性现金流净额

正常情况：经营性现金流 ≈ 净利润（或更高）
危险信号：经营性现金流 << 净利润（< 50%）

原因：应收账款暴增、存货积压、预付账款异常
```

### 10.3 估值安全边际设定

| 安全边际 | 估值折扣 | 适用场景 |
|----------|----------|----------|
| 极度保守 | 估值 × 50% | 高风险、高不确定性 |
| 保守 | 估值 × 70% | 中等风险 |
| 合理 | 估值 × 85% | 低风险、高确定性 |
| 成长溢价 | 估值 × 100-120% | 高成长、护城河深 |

### 11.1 基础FCF计算

```python
def calculate_fcff(ebit, tax_rate, depreciation, capex, wc_increase):
    """
    计算企业自由现金流(FCFF)

    参数:
        ebit: 息税前利润
        tax_rate: 有效税率
        depreciation: 折旧与摊销
        capex: 资本支出
        wc_increase: 营运资本增加

    返回:
        float: FCFF
    """
    nopat = ebit * (1 - tax_rate)
    fcff = nopat + depreciation - capex - wc_increase
    return fcff

def calculate_fcfe(net_income, depreciation, capex, wc_increase, net_borrowing):
    """
    计算股权自由现金流(FCFE)
    """
    fcfe = net_income + depreciation - capex - wc_increase + net_borrowing
    return fcfe

# 示例

print(f"FCFF = {fcff} 百万元")  # 结果: 52.5
```

### 11.2 WACC计算

```python
def calculate_wacc(equity_value, debt_value, cost_of_equity, cost_of_debt, tax_rate):
    """
    计算加权平均资本成本(WACC)
    """
    total_capital = equity_value + debt_value
    equity_weight = equity_value / total_capital
    debt_weight = debt_value / total_capital

    wacc = equity_weight * cost_of_equity + debt_weight * cost_of_debt * (1 - tax_rate)

    return {
        'WACC': wacc,
        '股权权重': equity_weight,
        '债务权重': debt_weight
    }

def capm(rf, beta, market_risk_premium, size_premium=0, company_premium=0):
    """
    CAPM计算股权成本
    """
    re = rf + beta * market_risk_premium + size_premium + company_premium
    return re

# 示例
wacc_result = calculate_wacc(
    equity_value=1000, 
    debt_value=400, 
    cost_of_equity=0.096, 
    cost_of_debt=0.05, 
    tax_rate=0.25
)
print(wacc_result)
```

### 11.3 完整DCF估值模型

```python
class DCFValuation:
    def __init__(self):
        self.revenue_forecast = []
        self.ebit_margin = 0.15
        self.tax_rate = 0.25
        self.da_ratio = 0.05
        self.capex_ratio = 0.08
        self.wc_ratio = 0.03
        self.wacc = 0.10
        self.terminal_growth = 0.03

    def set_forecast(self, base_revenue, growth_rates):
        """设置收入预测"""
        self.revenue_forecast = [base_revenue]
        for g in growth_rates:
            self.revenue_forecast.append(self.revenue_forecast[-1] * (1 + g))
        self.revenue_forecast = self.revenue_forecast[1:]  # 去掉基期

    def calculate_fcff_series(self):
        """计算FCFF序列"""
        fcff_list = []
        prev_revenue = self.revenue_forecast[0] / (1 + 0.10)  # 估算基期收入

        for revenue in self.revenue_forecast:
            ebit = revenue * self.ebit_margin
            nopat = ebit * (1 - self.tax_rate)
            da = revenue * self.da_ratio
            capex = revenue * self.capex_ratio
            wc_increase = (revenue - prev_revenue) * self.wc_ratio

            fcff = nopat + da - capex - wc_increase
            fcff_list.append(fcff)
            prev_revenue = revenue

        return fcff_list

    def calculate_terminal_value(self, fcff_final):
        """计算终值（永续增长模型）"""
        tv = fcff_final * (1 + self.terminal_growth) / (self.wacc - self.terminal_growth)
        return tv

    def value(self):
        """计算企业价值"""
        fcff_series = self.calculate_fcff_series()
        n = len(fcff_series)

        # 预测期现值
        pv_forecast = sum([fcff / (1 + self.wacc)**(i+1) for i, fcff in enumerate(fcff_series)])

        # 终值
        tv = self.calculate_terminal_value(fcff_series[-1])
        pv_tv = tv / (1 + self.wacc)**n

        # 企业价值
        ev = pv_forecast + pv_tv

        return {
            '预测期FCF': fcff_series,
            '预测期现值': pv_forecast,
            '终值': tv,
            '终值现值': pv_tv,
            '企业价值(EV)': ev
        }

# 使用示例
model = DCFValuation()
model.set_forecast(base_revenue=1000, growth_rates=[0.10, 0.10, 0.08, 0.06, 0.05])
result = model.value()
print(result)
```

### 11.4 敏感性分析

```python
import pandas as pd

def sensitivity_analysis(base_fcff, wacc_range, growth_range, n_years=5):
    """
    DCF敏感性分析矩阵
    """
    results = pd.DataFrame(index=wacc_range, columns=growth_range)

    for wacc in wacc_range:
        for g in growth_range:
            if g >= wacc:
                results.loc[wacc, g] = 'N/A'
                continue

            # 简化：假设FCF恒定增长
            fcf = [base_fcff * (1.1)**i for i in range(n_years)]

            # 预测期现值
            pv = sum([fcf[i] / (1 + wacc)**(i+1) for i in range(n_years)])

            # 终值
            tv = fcf[-1] * (1 + g) / (wacc - g)
            pv_tv = tv / (1 + wacc)**n_years

            results.loc[wacc, g] = pv + pv_tv

    return results

# 生成敏感性矩阵
wacc_range = [0.08, 0.09, 0.10, 0.11, 0.12]
growth_range = [0.02, 0.03, 0.04]
matrix = sensitivity_analysis(52.5, wacc_range, growth_range)
print(matrix)
```

## 十二、特殊行业DCF应用

### 12.1 银行业

**调整要点**：
- 使用FCFE而非FCFF（债务是经营资产，难以区分）
- 资本结构特殊，监管资本要求（CAR）是硬约束
- 终值用P/B或P/E倍数更常见
- 关注净息差（NIM）、不良贷款率、拨备覆盖率

### 12.2 周期性行业（钢铁、化工、航运）

**调整要点**：
- 预测需覆盖完整周期（5-7年）
- 使用正常化盈利（剔除周期高点/低点）
- 终值用退出倍数法更合适
- 敏感性分析尤为重要
- 商品价格假设是关键变量

### 12.3 科技/互联网公司

**调整要点**：
- 早期FCF为负，需延长预测期（10年+）
- 关注用户增长、ARPU、LTV/CAC
- 终值占比通常较高（70%+）
- 情景分析比单点估值更重要
- 技术迭代风险需纳入敏感性分析

### 12.4 新能源/ESG投资

**调整要点**：
- 引入ESG调整因子（碳减排收益、政策补贴）
- 政策补贴影响现金流预测（补贴退坡风险）
- 技术迭代风险（电池技术路线、光伏效率）
- 终值可能受能源转型影响
- 碳价、电价是关键变量

### 12.5 生物医疗/创新药

**调整要点**：
- 管线估值法（rNPV，风险调整净现值）
- 考虑研发失败概率（各阶段成功率）
- 监管审批不确定性（FDA/NMPA）
- 峰值销售额预测（Peak Sales）
- 专利悬崖影响（专利到期后仿制药竞争）

**rNPV公式**：
```
rNPV = Σ [峰值销售额 × 市场份额 × 成功概率_t / (1 + WACC)^t]

成功概率参考：
- 临床前 → Phase I: 60%
- Phase I → Phase II: 40%
- Phase II → Phase III: 30%
- Phase III → 获批: 60%
```

### 12.6 基础设施/公用事业

**调整要点**：
- 收入稳定，增长低（2%-3%）
- 资本支出大但可预测（维护+扩容）
- 监管收益率是核心假设（如允许ROE）
- 终值占比高，永续增长模型适用
- 折旧政策影响大（长期资产）

| FCFF→FCFE | FCFF - 利息×(1-T) + 净借债 | 两种现金流转换 |
| WACC | E/(E+D)×Re + D/(E+D)×Rd×(1-T) | 加权平均资本成本 |
| CAPM | Re = Rf + β×(Rm-Rf) | 股权成本 |
| β去杠杆 | β_资产 = β_权益 / [1+(1-T)×D/E] | 去除财务杠杆影响 |
| β加杠杆 | β_权益 = β_资产 × [1+(1-T)×D/E] | 加入目标杠杆 |
| 永续增长TV | FCF_n×(1+g)/(WACC-g) | 终值计算 |
| 退出倍数TV | EBITDA_n × Multiple | 终值计算 |
| EV | PV(FCF) + PV(TV) | 企业价值 |
| 股权价值 | EV - Debt + Cash - Minority Interest | 股权价值 |
| 每股价值 | 股权价值 / 稀释后总股本 | 每股内在价值 |
| 营运资本 | 应收+存货-应付+其他经营性项目 | 经营资金占用 |
| 净借债 | 新发行债务 - 偿还本金 | 债务变动 |
