## 一、DCF估值核心原理

### 1.1 核心思想

DCF（Discounted Cash Flow，现金流折现法）的核心逻辑是：

> **企业的内在价值 = 未来所有自由现金流的现值之和**

基于"货币时间价值"原理：今天的1元钱比明天的1元钱更值钱。

### 1.2 基础公式

```
企业价值 = Σ [FCF_t / (1 + WACC)^t] + TV / (1 + WACC)^n

其中：
- FCF_t = 第t年的自由现金流
- WACC = 加权平均资本成本（折现率）
- TV = 终值（预测期后的永续价值）
- n = 详细预测期年数（通常5-10年）
```

### 1.3 DCF vs 其他估值方法

| 方法 | 适用场景 | 优点 | 缺点 |
|------|----------|------|------|
| **DCF** | 稳定现金流企业 | 理论基础扎实、考虑时间价值 | 假设敏感、预测难度大 |
| **P/E倍数** | 盈利稳定企业 | 简单直观、市场可比 | 受会计政策影响、周期性强 |
| **EV/EBITDA** | 资本结构差异大 | 剔除折旧影响、跨国可比 | 忽视资本支出 |
| **P/B** | 重资产行业 | 账面价值稳定 | 忽视无形资产 |
| **DDM** | 高分红企业 | 直接对应股东回报 | 不适用于低分红企业 |

## 二、DCF模型构建步骤

### 2.1 完整流程图

```
步骤1: 确定预测期（通常5-10年详细预测 + 终值）
    ↓
步骤2: 预测未来自由现金流（FCF）
    - 收入预测
    - 成本费用预测
    - 资本支出预测
    - 营运资本变动预测
    ↓
步骤3: 计算折现率（WACC）
    - 股权成本（CAPM）
    - 债务成本
    - 资本结构权重
    ↓
步骤4: 计算终值（Terminal Value）
    - 永续增长模型（Gordon Growth）
    - 退出倍数法（Exit Multiple）
    ↓
步骤5: 折现并汇总
    - 预测期FCF现值
    - 终值现值
    - 企业价值（EV）
    ↓
步骤6: 从企业价值推导股权价值
    - 加：现金及等价物
    - 减：有息负债
    - 减：少数股东权益
    - 减：优先股
    = 股权价值
    ↓
步骤7: 计算每股价值
    - 股权价值 / 总股本
```

### 2.2 关键参数一览

| 参数 | 典型范围 | 确定方法 |
|------|----------|----------|
| 预测期 | 5-10年 | 行业周期、企业生命周期 |
| 收入增长率 | 5%-30% | 历史趋势、行业增速、市占率 |
| 营业利润率 | 10%-25% | 历史均值、行业对标 |
| 资本支出/收入 | 3%-15% | 产能规划、折旧政策 |
| WACC | 8%-12% | CAPM + 债务成本 |
| 永续增长率 | 2%-4% | GDP增速、行业成熟期 |

## 三、自由现金流(FCF)计算

### 3.1 FCFF（企业自由现金流）

**公式**：
```
FCFF = EBIT × (1 - 税率) + 折旧摊销 - 资本支出 - 营运资本增加

或：
FCFF = 净利润 + 利息费用×(1-税率) + 折旧摊销 - 资本支出 - 营运资本增加
```

**各科目详解**：

| 科目 | 计算逻辑 | 数据来源 |
|------|----------|----------|
| EBIT | 营业收入 - 营业成本 - 销售/管理/研发费用 | 利润表 |
| 税率 | 有效税率（非名义税率） | 历史有效税率均值 |
| 折旧摊销 | 固定资产折旧 + 无形资产摊销 | 现金流量表附注 |
| 资本支出 | 维持性资本支出 + 扩张性资本支出 | 现金流量表/管理层指引 |
| 营运资本增加 | Δ(应收账款+存货-应付账款) + Δ其他流动资产/负债 | 资产负债表变动 |

### 3.2 FCFE（股权自由现金流）

**公式**：
```
FCFE = 净利润 + 折旧摊销 - 资本支出 - 营运资本增加 + 净借债

或：
FCFE = FCFF - 利息费用×(1-税率) + 净借债
```

**适用场景**：
- FCFF：用于计算企业整体价值（EV），再用价值恒等式推导股权价值
- FCFE：直接计算股权价值，但需预测资本结构变化

### 3.3 从三张报表推导FCFF

```
利润表                资产负债表           现金流量表
营业收入               应收账款            经营活动现金流
- 营业成本             + 存货              - 资本支出
= 毛利                 - 应付账款          = 自由现金流
- 销售/管理/研发费用   = 营运资本
= EBIT
- 利息费用
= 税前利润
- 所得税
= 净利润
```

## 四、折现率(WACC)计算

### 4.1 WACC公式

```
WACC = E/(E+D) × Re + D/(E+D) × Rd × (1 - T)

其中：
- E = 股权市场价值
- D = 债务市场价值
- Re = 股权成本
- Rd = 债务成本
- T = 有效税率
```

### 4.2 股权成本(Re)——CAPM模型

```
Re = Rf + β × (Rm - Rf) + 风险溢价调整

其中：
- Rf = 无风险利率（通常用10年期国债收益率）
- β = 股票系统性风险系数
- Rm - Rf = 市场风险溢价（通常4%-7%）
```

**β系数确定**：
- 有公开交易数据：回归分析（股票收益率 vs 市场收益率）
- 无公开交易数据：参考同行业上市公司β，去杠杆后重新加杠杆

**去杠杆/加杠杆公式**：
```
β_资产 = β_权益 / [1 + (1-T) × D/E]        // 去杠杆
β_权益 = β_资产 × [1 + (1-T) × D/E]        // 加杠杆
```

### 4.3 债务成本(Rd)

| 企业类型 | Rd确定方法 |
|----------|------------|
| 上市公司 | 债券到期收益率(YTM) |
| 非上市公司 | 银行贷款利率、同行业债券利率 |
| 无信用评级 | 参考同行业同规模企业利率 |

### 4.4 资本结构权重

**市场价值权重**（推荐）：
```
E = 股价 × 总股本
D = 短期借款 + 长期借款 + 应付债券（账面价值近似市场价值）
```

**注意**：
- 使用目标资本结构（而非当前结构）更合理
- 对于高成长企业，逐步向目标结构过渡

## 五、终值(Terminal Value)计算

### 5.1 永续增长模型（Gordon Growth Model）

**公式**：
```
TV = FCF_n × (1 + g) / (WACC - g)

其中：
- FCF_n = 预测期最后一年自由现金流
- g = 永续增长率（通常≤GDP增速，2%-4%）
- WACC = 加权平均资本成本
```

**永续增长率确定原则**：
- 不能超过WACC（否则TV为负，无意义）
- 通常≤长期GDP增速 + 通胀率
- 成熟期企业：2%-3%
- 成长期企业：3%-4%

### 5.2 退出倍数法（Exit Multiple）

**公式**：
```
TV = EBITDA_n × 退出倍数

常见倍数：
- EV/EBITDA：制造业 6-10x，科技 10-15x，消费 8-12x
- EV/Revenue：SaaS 5-10x，平台型 3-8x
```

**两种方法对比**：

| 方法 | 适用场景 | 优点 | 缺点 |
|------|----------|------|------|
| 永续增长 | 稳定增长企业 | 与DCF逻辑一致 | 对g敏感 |
| 退出倍数 | 周期性/并购场景 | 反映市场定价 | 受市场情绪影响 |

## 六、企业价值与股权价值换算

### 6.1 价值恒等式

```
企业价值(EV) = 股权价值 + 有息负债 - 现金及等价物 + 少数股东权益 + 优先股

股权价值 = EV - 有息负债 + 现金及等价物 - 少数股东权益 - 优先股
```

### 6.2 从EV到每股价值

```
每股价值 = 股权价值 / 总股本

需考虑：
- 期权/可转债稀释（ treasury stock method ）
- 限制性股票
- 库存股
```

### 6.3 价值构成示意

```
企业价值(EV)
├── 股权价值
│   ├── 普通股价值
│   ├── 少数股东权益
│   └── 优先股价值
├── 债务价值
│   ├── 短期借款
│   ├── 长期借款
│   └── 应付债券
└── 现金及等价物（减项）
```

## 七、实战案例深度拆解

### 案例一：台积电DCF估值（三情景分析）

#### 假设参数

| 参数 | 悲观 | 保守 | 乐观 |
|------|------|------|------|
| 当前FCF | 1,500亿台币 | 1,500亿台币 | 1,500亿台币 |
| 第一阶段增长率(2025-2027) | 15% | 20% | 25% |
| 第二阶段增长率(2028-2030) | 10% | 15% | 20% |
| 永续增长率 | 2% | 3% | 4% |
| WACC | 10% | 9% | 8% |

#### 保守情景计算过程

**第一阶段（2025-2027，增长率20%）**：
- 2025年：1,500 × 1.20 / 1.09¹ = 1,651亿
- 2026年：1,500 × 1.20² / 1.09² = 1,816亿
- 2027年：1,500 × 1.20³ / 1.09³ = 1,998亿

**第二阶段（2028-2030，增长率15%）**：
- 2028年：1,500 × 1.20³ × 1.15 / 1.09⁴ = 2,111亿
- 2029年：1,500 × 1.20³ × 1.15² / 1.09⁵ = 2,230亿
- 2030年：1,500 × 1.20³ × 1.15³ / 1.09⁶ = 2,356亿

**终值计算（2031年后，永续增长3%）**：
```
终值 = 2030年FCF × (1+3%) / (9%-3%) = 2,356 × 1.03 / 0.06 = 40,445亿
终值现值 = 40,445 / 1.09⁷ = 21,620亿
```

**企业价值**：
- 预测期现值：约12,000亿
- 终值现值：约21,620亿
- **总EV ≈ 33,620亿台币**
- **每股价值 ≈ 1,737元**（vs 2024年底股价1,075元）

#### 三情景结果汇总

| 情景 | 内在价值 | 每股价值 | vs 股价(1,075元) |
|------|----------|----------|-----------------|
| 悲观 | 35,000亿 | 1,351元 | +25.7% |
| 保守 | 45,000亿 | 1,737元 | +61.6% |
| 乐观 | 58,000亿 | 2,239元 | +108.3% |

**结论**：所有情景下均低估，但乐观假设可能过于激进。

### 案例二：Google DCF估值（完整流程）

#### 关键假设

| 参数 | 数值 |
|------|------|
| 当前收入 | $289,531M |
| 收入增长率 | 14.4% |
| 营业利润率(标准化) | 25.6% |
| 税率 | 21% |
| WACC | 9.65% |
| 永续增长率 | 4.25% |
| 债务 | $25,713M |
| 现金 | $110,916M |
| 总股本 | 12,908M |

#### 计算步骤

**Step 1: 收入预测**
```
Year 1: 289,531 × 1.144 = 331,224
Year 2: 331,224 × 1.144 = 378,920
...
```

**Step 2: EBIT计算**
```
EBIT = 收入 × 营业利润率 = 331,224 × 25.6% = 84,793
```

**Step 3: NOPAT计算**
```
NOPAT = EBIT × (1-税率) = 84,793 × 79% = 66,986
```

**Step 4: 再投资计算**
```
Sales-to-capital ratio = Sales / (Equity + Debt - Cash)
                      = 289,531 / (267,141 + 29,432 - 118,332)
                      = 1.62
```

**Step 5: FCFF计算**
```
FCFF = NOPAT - 再投资
     = 66,986 - (收入增量 / 1.62)
```

**Step 6: 折现**
```
PV = FCFF / (1 + WACC)^n
Year 1 PV = 45,236 / 1.0965¹ = 41,255
...
```

**Step 7: 终值**
```
Terminal FCFF = 111,843（基于4.25%增长）
Terminal Value = 111,843 / (9.65% - 4.25%) × 折现因子 = 1,306,688
```

**Step 8: 企业价值到股权价值**
```
Total EV = 1,593,662
Equity Value = 1,593,662 - 25,713 + 110,916 = 1,678,865
Fair Value per Share = 1,678,865 / 12,908 = $130.06
```

## 八、敏感性分析与情景建模

### 8.1 敏感性分析矩阵

以台积电保守情景为例：

| WACC \ 永续增长率 | 2% | 3% | 4% |
|-------------------|-----|-----|-----|
| **8%** | 2,100元 | 2,500元 | 3,200元 |
| **9%** | 1,500元 | 1,737元 | 2,100元 |
| **10%** | 1,100元 | 1,300元 | 1,500元 |
| **12%** | 800元 | 900元 | 1,000元 |

**关键发现**：
- WACC每变动1%，估值波动约12-15%
- 永续增长率每变动1%，估值波动约20-30%
- **WACC和永续增长率是最敏感的参数**

### 8.2 情景分析框架

| 情景 | 概率 | 关键假设 | 估值结果 | 投资决策 |
|------|------|----------|----------|----------|
| 悲观 | 25% | 增长放缓、竞争加剧 | 低估值 | 设定止损线 |
| 基准 | 50% | 正常经营、行业平均 | 中估值 | 核心参考 |
| 乐观 | 25% | 技术突破、市场扩张 | 高估值 | 设定止盈线 |

### 8.3 蒙特卡洛模拟

对关键参数进行概率分布假设：
- 收入增长率：正态分布 N(μ, σ²)
- WACC：三角分布（最小值、最可能值、最大值）
- 永续增长率：均匀分布

运行10,000次模拟，得到估值概率分布：
- P10（10%分位）：保守估值
- P50（中位数）：最可能估值
- P90（90%分位）：乐观估值

## 九、常见错误与注意事项

### 9.1 十大常见错误

| 错误 | 后果 | 正确做法 |
|------|------|----------|
| 1. 永续增长率 > WACC | TV为负，模型崩溃 | g必须 < WACC |
| 2. 使用净利润代替FCF | 高估/低估价值 | 必须用自由现金流 |
| 3. 忽略营运资本变动 | 现金流预测失真 | 详细预测应收、存货、应付 |
| 4. 资本支出假设不合理 | 增长假设与再投资脱节 | Sales-to-capital ratio验证 |
| 5. WACC计算错误 | 折现率偏差导致估值失真 | 用CAPM+债务成本，考虑税率 |
| 6. 预测期太短 | 终值占比过高（>80%） | 至少5-10年详细预测 |
| 7. 忽略稀释效应 | 每股价值高估 | 考虑期权、可转债 |
| 8. 使用账面价值而非市场价值 | 资本结构权重错误 | 股权用市值，债务用市场价值 |
| 9. 过度乐观的增长假设 | 估值虚高 | 参考行业增速、市占率上限 |
| 10. 忽视敏感性分析 | 风险认知不足 | 必须做WACC和g的敏感性分析 |

### 9.2 质量检查清单

- [ ] 预测期FCF是否为正？（若长期为负，需检查商业模式）
- [ ] 终值占比是否 < 70%？（过高则预测期不足）
- [ ] 收入增长率是否逐步收敛至行业均值？
- [ ] 营业利润率是否稳定或合理变化？
- [ ] 资本支出是否与收入增长匹配？
- [ ] WACC是否在合理范围（8%-12%）？
- [ ] 永续增长率是否 ≤ GDP增速？
- [ ] 是否进行了敏感性分析？
- [ ] 是否与相对估值法交叉验证？

## 十、Python自动化实现

### 10.1 基础DCF计算

```python
def dcf_valuation(fcf_forecast, wacc, terminal_growth, terminal_method='perpetuity'):
    """
    DCF估值基础计算

    参数:
        fcf_forecast: 预测期FCF列表 [FCF1, FCF2, ..., FCFn]
        wacc: 加权平均资本成本
        terminal_growth: 永续增长率
        terminal_method: 终值方法 ('perpetuity' 或 'multiple')

    返回:
        dict: 包含企业价值、终值、预测期现值等
    """
    n = len(fcf_forecast)

    # 预测期现值
    pv_forecast = sum([fcf / (1 + wacc)**(i+1) for i, fcf in enumerate(fcf_forecast)])

    # 终值计算
    if terminal_method == 'perpetuity':
        terminal_value = fcf_forecast[-1] * (1 + terminal_growth) / (wacc - terminal_growth)
    else:
        # 退出倍数法需额外参数
        terminal_value = fcf_forecast[-1] * 10  # 简化示例

    pv_terminal = terminal_value / (1 + wacc)**n

    # 企业价值
    enterprise_value = pv_forecast + pv_terminal

    return {
        '预测期现值': round(pv_forecast, 2),
        '终值': round(terminal_value, 2),
        '终值现值': round(pv_terminal, 2),
        '企业价值(EV)': round(enterprise_value, 2)
    }

# 示例：台积电保守情景
fcf = [1651, 1816, 1998, 2111, 2230, 2356, 2500, 2650, 2800, 3000]  # 十亿台币
result = dcf_valuation(fcf, wacc=0.09, terminal_growth=0.03)
```

### 10.2 WACC计算

```python
def calculate_wacc(equity_value, debt_value, cost_of_equity, cost_of_debt, tax_rate):
    """
    计算WACC
    """
    total_capital = equity_value + debt_value
    equity_weight = equity_value / total_capital
    debt_weight = debt_value / total_capital

    wacc = equity_weight * cost_of_equity + debt_weight * cost_of_debt * (1 - tax_rate)

    return {
        'WACC': round(wacc, 4),
        '股权权重': round(equity_weight, 4),
        '债务权重': round(debt_weight, 4)
    }

def capm(rf, beta, market_risk_premium, size_premium=0, company_premium=0):
    """
    CAPM计算股权成本
    """
    re = rf + beta * market_risk_premium + size_premium + company_premium
    return re

# 示例
wacc_result = calculate_wacc(
    equity_value=1000, 
    debt_value=300, 
    cost_of_equity=0.12, 
    cost_of_debt=0.05, 
    tax_rate=0.25
)
# WACC = (1000/1300)×12% + (300/1300)×5%×75% = 10.08%
```

### 10.3 敏感性分析

```python
import pandas as pd

def sensitivity_analysis(base_fcf, wacc_range, growth_range, n_years=10):
    """
    DCF敏感性分析矩阵
    """
    results = pd.DataFrame(index=wacc_range, columns=growth_range)

    for wacc in wacc_range:
        for g in growth_range:
            if g >= wacc:
                results.loc[wacc, g] = 'N/A'
                continue

            # 简化：假设FCF恒定增长
            fcf = [base_fcf * (1.1)**i for i in range(n_years)]  # 10%增长
            val = dcf_valuation(fcf, wacc, g)
            results.loc[wacc, g] = val['企业价值(EV)']

    return results

# 生成敏感性矩阵
wacc_range = [0.08, 0.09, 0.10, 0.11, 0.12]
growth_range = [0.02, 0.03, 0.04]
matrix = sensitivity_analysis(1500, wacc_range, growth_range)
```

### 10.4 完整DCF模型类

```python
class DCFModel:
    def __init__(self, company_name, currency='CNY'):
        self.company = company_name
        self.currency = currency
        self.revenue_forecast = []
        self.margin_assumptions = {}
        self.capex_assumptions = {}
        self.wacc = 0.10
        self.terminal_growth = 0.03

    def set_revenue_forecast(self, revenues):
        """设置收入预测"""
        self.revenue_forecast = revenues

    def set_margins(self, ebitda_margin, tax_rate, d_and_a_pct):
        """设置利润率假设"""
        self.margin_assumptions = {
            'ebitda_margin': ebitda_margin,
            'tax_rate': tax_rate,
            'd_and_a_pct': d_and_a_pct
        }

    def calculate_fcff(self):
        """计算FCFF序列"""
        fcff_list = []
        for rev in self.revenue_forecast:
            ebitda = rev * self.margin_assumptions['ebitda_margin']
            da = rev * self.margin_assumptions['d_and_a_pct']
            ebit = ebitda - da
            nopat = ebit * (1 - self.margin_assumptions['tax_rate'])
            capex = rev * 0.05  # 简化假设
            wc_change = rev * 0.02  # 简化假设
            fcff = nopat + da - capex - wc_change
            fcff_list.append(fcff)
        return fcff_list

    def value(self):
        """计算企业价值"""
        fcff = self.calculate_fcff()
        return dcf_valuation(fcff, self.wacc, self.terminal_growth)
```

## 十一、特殊行业DCF应用

### 11.1 银行业

**调整要点**：
- 使用股权自由现金流（FCFE）而非FCFF
- 资本结构特殊，债务是经营资产
- 关注监管资本要求（CAR）
- 终值用P/B或P/E倍数更常见

### 11.2 周期性行业（钢铁、化工）

**调整要点**：
- 预测需覆盖完整周期（5-7年）
- 使用正常化盈利（剔除周期高点/低点）
- 终值用退出倍数法更合适
- 敏感性分析尤为重要

### 11.3 科技/互联网公司

**调整要点**：
- 早期FCF为负，需延长预测期
- 关注用户增长、ARPU、LTV/CAC
- 终值占比通常较高
- 情景分析比单点估值更重要

### 11.4 新能源/ESG投资

**调整要点**：
- 引入ESG调整因子（碳减排收益等）
- 政策补贴影响现金流预测
- 技术迭代风险需纳入敏感性分析
- 终值可能受能源转型影响

### 11.5 生物医疗/创新药

**调整要点**：
- 管线估值法（rNPV）
- 考虑研发失败概率
- 监管审批不确定性
- 峰值销售额预测
- 专利悬崖影响

## 附录：关键公式速查表

| 公式 | 表达式 | 用途 |
|------|--------|------|
| FCFF | EBIT×(1-T) + D&A - CapEx - ΔWC | 企业自由现金流 |
| FCFE | 净利润 + D&A - CapEx - ΔWC + Net Borrowing | 股权自由现金流 |
| WACC | E/(E+D)×Re + D/(E+D)×Rd×(1-T) | 加权平均资本成本 |
| CAPM | Re = Rf + β×(Rm-Rf) | 股权成本 |
| 永续增长TV | FCF_n×(1+g)/(WACC-g) | 终值计算 |
| 退出倍数TV | EBITDA_n × Multiple | 终值计算 |
| EV | PV(FCF) + PV(TV) | 企业价值 |
| 股权价值 | EV - Debt + Cash - Minority Interest | 股权价值 |
| 每股价值 | 股权价值 / 总股本 | 每股内在价值 |
