## 一、PE与PB核心概念

### 1.1 基础定义

| 指标 | 全称 | 公式 | 通俗理解 |
|------|------|------|----------|
| **PE** | 市盈率 (Price-to-Earnings Ratio) | 股价 / 每股收益 | **回本年限**：按当前盈利，多少年能收回投资成本 |
| **PB** | 市净率 (Price-to-Book Ratio) | 股价 / 每股净资产 | **家底折扣**：买这家公司，是打几折买它的净资产 |

### 1.2 核心逻辑

- **PE关注"盈利能力"**：愿意为每1元利润支付多少价格
- **PB关注"资产安全垫"**：愿意为每1元净资产支付多少价格
- **两者互补**：PE看"赚多少"，PB看"有多少"

### 1.3 与其他估值方法的关系

```
估值方法谱系：

绝对估值法                    相对估值法
    |                            |
    DCF (现金流折现)      PE → 看盈利
    |                     PB → 看资产
    |                     PS → 看收入
    |                     EV/EBITDA → 看经营
    |                     PEG → 看成长
```

## 二、PE市盈率详解

### 2.1 PE的三种类型

| 类型 | 公式 | 特点 | 适用场景 |
|------|------|------|----------|
| **静态PE** | 股价 / 上一年度EPS | 数据确定，但滞后 | 历史回顾、稳健分析 |
| **动态PE** | 股价 / 预测年度EPS | 前瞻性强，但主观 | 成长型投资、业绩预测 |
| **PE-TTM** | 股价 / 最近12个月EPS | 兼顾时效与真实 | **最推荐使用**，日常分析 |

### 2.2 PE的经济含义

```
PE = 10 → 投资10年回本（假设利润不变）
PE = 20 → 投资20年回本
PE = 50 → 投资50年回本
```

**但注意**：PE低≠便宜，PE高≠贵。需结合成长性（PEG）、行业特性、盈利质量综合判断。

### 2.3 PE的适用与局限

**适用场景**：
- 盈利稳定、可预测的成熟企业
- 消费、医药、公用事业等弱周期行业
- 同行业横向对比

**不适用场景**：
- 亏损企业（PE为负或无意义）
- 强周期行业（利润波动剧烈）
- 资产重于盈利的行业（如银行、地产）
- 初创/高成长企业（利润尚未释放）

### 2.4 PE的深层解读

| PE区间 | 可能含义 | 投资策略 |
|--------|----------|----------|
| < 10 | 价值洼地或价值陷阱 | 需排查基本面恶化 |
| 10-20 | 合理估值区间 | 结合成长性判断 |
| 20-40 | 成长溢价 | 确认成长可持续性 |
| > 40 | 高成长预期或泡沫 | 警惕业绩不及预期 |
| 负值 | 亏损企业 | 切换PB或PS估值 |

## 三、PB市净率详解

### 3.1 PB的计算与含义

```
PB = 股价 / 每股净资产
   = 总市值 / 股东权益（净资产）

每股净资产 = (股本 + 资本公积 + 盈余公积 + 未分配利润) / 总股本
```

**PB = 1**：股价 = 净资产，按账面价值买卖
**PB < 1**："破净"，股价低于净资产（可能低估或资产质量差）
**PB > 1**：市场给予净资产溢价（品牌、技术、成长预期）

### 3.2 PB的适用与局限

**适用场景**：
- 重资产行业：银行、钢铁、煤炭、房地产
- 周期性行业：利润波动大，但净资产相对稳定
- 亏损企业：PE失效时，PB提供估值锚
- 并购/清算场景：资产价值是底线

**不适用场景**：
- 轻资产/科技行业：净资产少，PB极高或失真
- 无形资产主导：品牌、专利、用户价值未体现在账面
- 资产质量差：账面净资产 ≠ 可变现价值

### 3.3 PB的深层解读

| PB区间 | 可能含义 | 投资策略 |
|--------|----------|----------|
| < 0.5 | 深度破净 | 排查资产减值风险 |
| 0.5-1.0 | 破净 | 关注ROE是否支撑 |
| 1.0-1.5 | 轻度溢价 | 合理区间 |
| 1.5-3.0 | 正常溢价 | 结合ROE判断 |
| > 3.0 | 高溢价 | 需强成长或高ROE支撑 |

## 四、PE与PB对比分析

### 4.1 核心差异对比

| 维度 | PE (市盈率) | PB (市净率) |
|------|-------------|-------------|
| **关注焦点** | 盈利能力 | 资产价值 |
| **分子** | 股价 | 股价 |
| **分母** | 每股收益(EPS) | 每股净资产(BPS) |
| **核心问题** | "每1元利润值多少钱？" | "每1元净资产值多少钱？" |
| **适用行业** | 消费、医药、科技 | 银行、钢铁、地产、周期 |
| **盈利要求** | 必须盈利 | 可亏损 |
| **周期敏感性** | 高（利润波动大） | 低（净资产相对稳定） |
| **资产反映** | 间接（通过盈利） | 直接 |
| **无形资产** | 部分反映 | 难以反映 |
| **操纵难度** | 较易（会计调节利润） | 较难（资产审计严格） |

### 4.2 选择决策树

```
企业是否盈利？
    ├── 否 → 使用PB（或PS/EV）
    └── 是 → 利润是否稳定？
            ├── 否（强周期）→ 优先PB，PE辅助
            └── 是 → 资产是否重要？
                    ├── 是（重资产）→ PE + PB结合
                    └── 否（轻资产）→ 优先PE，PEG辅助
```

### 4.3 组合使用策略

| 场景 | 推荐组合 | 逻辑 |
|------|----------|------|
| 银行股 | PB为主，PE为辅 | 高杠杆、利润波动、资产质量关键 |
| 消费股 | PE为主，PB参考 | 品牌溢价、轻资产、盈利稳定 |
| 周期股 | PB为主，PE反向 | 利润随周期波动，净资产更稳定 |
| 科技股 | PE+PEG，PB参考 | 成长性强，需考虑增速 |
| 困境企业 | PB为主 | 盈利为负或极低，资产是底线 |

## 五、PE/PB/ROE黄金三角关系

### 5.1 核心公式

```
PB = PE × ROE

推导：
PB = 股价 / 每股净资产
PE = 股价 / 每股收益
ROE = 每股收益 / 每股净资产

因此：PE × ROE = (股价/EPS) × (EPS/BPS) = 股价/BPS = PB
```

### 5.2 投资黄金标准

> **"用好价格，买好公司"**

| 组合 | 特征 | 策略 |
|------|------|------|
| **高ROE + 低PE + 低PB** | 优质低估 | **黄金标的**，市场错杀或情绪低迷 |
| **高ROE + 高PE + 高PB** | 优质高估 | 好公司但价格透支，等待回调 |
| **低ROE + 低PE + 低PB** | 价值陷阱 | 基本面恶化，便宜是因为缺乏价值 |
| **低ROE + 高PE + 高PB** | 泡沫/炒作 | 远离 |

### 5.3 ROE的门槛标准

- **巴菲特标准**：连续5年ROE > 15%，视为有护城河
- **筛选门槛**：ROE > 10%（及格线），ROE > 20%（优秀）
- **持续性**：关注ROE的稳定性，而非单年高点

## 六、实战案例深度拆解

### 案例一：某公司股票基础估值

#### 财务数据

| 指标 | 数值 |
|------|------|
| 股价 | 20元 |
| 每股收益(EPS) | 2元 |
| 每股净资产(BPS) | 10元 |
| 净利润 | 2亿元 |
| 净资产 | 10亿元 |
| 总股本 | 1亿股 |

#### 计算

```
PE = 20 / 2 = 10倍
PB = 20 / 10 = 2倍
ROE = 2 / 10 = 20%

验证：PE × ROE = 10 × 20% = 2 = PB ✓
```

#### 解读

- PE=10：10年回本，处于合理偏低区间
- PB=2：2倍净资产，需ROE支撑
- ROE=20%：优秀水平，能支撑PB=2的估值
- **结论**：估值合理，若成长性良好可考虑买入

### 案例二：蓝天集团 vs 白云实业（同ROE不同估值）

#### 财务数据

| 指标 | 蓝天集团 | 白云实业 |
|------|----------|----------|
| 股价 | 30元 | 12元 |
| EPS | 3元 | 1.2元 |
| BPS | 10元 | 10元 |
| ROE | 30% | 12% |

#### 估值对比

| 指标 | 蓝天集团 | 白云实业 | 解读 |
|------|----------|----------|------|
| PE | 10倍 | 10倍 | **相同PE** |
| PB | 3倍 | 1.2倍 | **差异巨大** |
| ROE | 30% | 12% | 蓝天效率更高 |

#### 深度分析

**验证公式**：
- 蓝天：PE × ROE = 10 × 30% = 3 = PB ✓
- 白云：PE × ROE = 10 × 12% = 1.2 = PB ✓

**投资启示**：
- 相同PE，但蓝天PB更高，因为ROE更高
- 蓝天：高盈利效率支撑高PB，但需确认ROE可持续性
- 白云：低ROE导致低PB，若ROE提升空间大可关注
- **不能仅凭PE判断便宜与否，需结合ROE和PB**

### 案例三：银行股估值（PB为主）

#### 背景
某银行股：股价5元，EPS 0.5元，BPS 8元，ROE 6%

#### 估值

| 指标 | 数值 | 行业对比 |
|------|------|----------|
| PE | 10倍 | 行业平均8-12倍 |
| PB | 0.625倍 | **破净** |
| ROE | 6% | 行业平均10-12% |

#### 分析

- **PB < 1**：破净，市场担忧资产质量（坏账、非标资产）
- **ROE偏低**：盈利能力弱于同行
- **PE看似合理**：但利润可能未充分计提风险
- **结论**：低PB反映资产质量担忧，需深入分析不良贷款率、拨备覆盖率

### 案例四：周期股陷阱（PE反向指标）

#### 背景
某钢铁股：周期顶峰时利润暴增，股价20元，EPS 5元，BPS 10元

#### 估值

| 指标 | 周期顶峰 | 周期低谷 |
|------|----------|----------|
| 股价 | 20元 | 8元 |
| EPS | 5元 | 0.5元 |
| PE | **4倍**（极低） | **16倍**（较高） |
| PB | 2倍 | 0.8倍 |

#### 陷阱分析

- **周期顶峰**：PE=4倍看似极度低估，实则利润即将暴跌
- **周期低谷**：PE=16倍看似高估，实则利润即将反弹
- **PB更稳定**：顶峰PB=2，低谷PB=0.8，更能反映真实估值
- **策略**：周期股应在PE高（利润低）时买入，PE低（利润高）时卖出

## 八、常见估值陷阱与规避

### 8.1 五大估值陷阱

| 陷阱 | 表象 | 真相 | 规避方法 |
|------|------|------|----------|
| **价值陷阱** | PE极低、PB极低 | 基本面恶化，ROE持续下滑 | 排查ROE趋势、行业前景 |
| **周期陷阱** | 周期顶峰PE极低 | 利润即将暴跌 | 用PB替代PE，反向操作 |
| **利润造假** | PE合理但现金流差 | 应收账款虚增利润 | 对比经营性现金流/净利润 |
| **杠杆陷阱** | ROE高但负债高 | 高杠杆放大ROE | 看ROIC、资产负债率 |
| **成长透支** | PE极高、PEG>2 | 价格透支未来多年增长 | 用PEG<1作为安全边际 |

### 8.2 利润质量检验

```
净利润 vs 经营性现金流净额

正常情况：经营性现金流 ≈ 净利润（或更高）
危险信号：经营性现金流 << 净利润（< 50%）

原因：应收账款暴增、存货积压、预付账款异常
```

### 8.3 估值安全边际设定

| 安全边际 | PE要求 | PB要求 | ROE要求 |
|----------|--------|--------|---------|
| 极度保守 | < 行业均值50% | < 1 | > 15% |
| 保守 | < 行业均值70% | < 行业均值70% | > 12% |
| 合理 | 行业均值 ±20% | 行业均值 ±20% | > 10% |
| 成长溢价 | 行业均值1-2倍 | 行业均值1-2倍 | > 15% |

## 九、Python自动化实现

### 9.1 基础估值计算

```python
def calculate_pe_pb(stock_price, eps, bps):
    """
    计算PE和PB

    参数:
        stock_price: 当前股价
        eps: 每股收益（Earnings Per Share）
        bps: 每股净资产（Book Value Per Share）

    返回:
        dict: PE、PB、ROE
    """
    pe = stock_price / eps if eps > 0 else float('inf')
    pb = stock_price / bps if bps > 0 else float('inf')
    roe = eps / bps if bps > 0 else 0

    return {
        'PE': round(pe, 2),
        'PB': round(pb, 2),
        'ROE': round(roe * 100, 2),  # 百分比
        '验证_PB': round(pe * roe, 2)  # 应等于PB
    }

# 示例
result = calculate_pe_pb(stock_price=20, eps=2, bps=10)
# 结果: {'PE': 10.0, 'PB': 2.0, 'ROE': 20.0, '验证_PB': 2.0}
```

### 9.2 批量筛选低估股票

```python
import pandas as pd

def screen_stocks(df, pe_max=20, pb_max=2, roe_min=15):
    """
    筛选低PE、低PB、高ROE的股票

    df列: stock_code, stock_name, price, eps, bps
    """
    df['PE'] = df['price'] / df['eps']
    df['PB'] = df['price'] / df['bps']
    df['ROE'] = df['eps'] / df['bps'] * 100

    # 筛选条件
    filtered = df[
        (df['PE'] > 0) & (df['PE'] < pe_max) &
        (df['PB'] > 0) & (df['PB'] < pb_max) &
        (df['ROE'] > roe_min)
    ].copy()

    # 综合评分：ROE越高越好，PE/PB越低越好
    filtered['score'] = (
        filtered['ROE'] / filtered['PE'] * 0.5 +
        filtered['ROE'] / filtered['PB'] * 0.5
    )

    return filtered.sort_values('score', ascending=False)

# 示例数据
data = {
    'stock_code': ['000001', '000002', '600000'],
    'stock_name': ['平安银行', '万科A', '浦发银行'],
    'price': [12, 18, 8],
    'eps': [1.2, 2.5, 0.8],
    'bps': [15, 20, 12]
}
df = pd.DataFrame(data)
result = screen_stocks(df, pe_max=15, pb_max=1.5, roe_min=8)
```

### 9.3 行业对比分析

```python
def industry_comparison(stocks_df, industry_col='industry'):
    """
    按行业分组计算平均PE、PB、ROE
    """
    industry_stats = stocks_df.groupby(industry_col).agg({
        'PE': ['mean', 'median', 'std'],
        'PB': ['mean', 'median', 'std'],
        'ROE': ['mean', 'median', 'std']
    }).round(2)

    return industry_stats

# 添加分位点分析
def add_percentile(df, col):
    """
    计算指标在历史数据中的分位点
    """
    df[f'{col}_percentile'] = df[col].rank(pct=True) * 100
    return df
```

### 9.4 历史分位点计算

```python
def calculate_percentile(current_value, historical_series):
    """
    计算当前值在历史数据中的分位点

    参数:
        current_value: 当前PE/PB值
        historical_series: 历史PE/PB序列

    返回:
        float: 分位点（0-100）
    """
    percentile = (historical_series < current_value).mean() * 100
    return round(percentile, 2)

# 示例：创业板指PE历史分位
historical_pe = [30, 35, 40, 45, 50, 55, 60, 50, 45, 42.68]
current_pe = 42.68
percentile = calculate_percentile(current_pe, historical_pe)
# 结果: 约47.51%（历史中位水平）
```

### 10.3 估值预警系统

```python
class ValuationAlert:
    def __init__(self):
        self.thresholds = {
            'PE': {'low': 5, 'high': 50},
            'PB': {'low': 0.3, 'high': 10},
            'ROE': {'low': 5, 'high': 30}
        }

    def check(self, stock_code, pe, pb, roe):
        """检查估值是否异常"""
        alerts = []

        if pe < self.thresholds['PE']['low']:
            alerts.append(f"PE={pe:.1f} 极低，可能存在价值陷阱")
        elif pe > self.thresholds['PE']['high']:
            alerts.append(f"PE={pe:.1f} 极高，可能存在泡沫")

        if pb < self.thresholds['PB']['low']:
            alerts.append(f"PB={pb:.1f} 破净严重，关注资产质量")

        if roe < self.thresholds['ROE']['low']:
            alerts.append(f"ROE={roe:.1f}% 偏低，盈利能力弱")

        return alerts
```
